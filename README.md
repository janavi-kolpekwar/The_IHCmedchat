# The_IHCmedchat
#### Chatbot developed using GPT-4o developing from scratch a chat web app using Streamlit software. The user is able to upload images and text to the OpenAI API and deploy this web app for free. This project is currently in the workings to be developed into a Chatbot for detecting the source of metastatic cancer using serious fluid immunohistochemistry image results and anonymized demographic patient data. We will conduct a series of 20 positive test cases and modify paramters during the development.
